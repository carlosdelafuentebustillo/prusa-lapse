# OrcaSlicer Native Integration & Seamless Timelapse Auto-Injection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a native OrcaSlicer Python plugin and WebApp integration that embeds the PrusaLapse dashboard into OrcaSlicer and automatically injects parked timelapse G-code (`M220 S99`) at every layer change during slicing.

**Architecture:** A lightweight, pure-Python OrcaSlicer plugin provides two capabilities: a Page Plugin (`PagesPluginCapabilityBase`) embedding the live dashboard via `wxWebView`, and a Slicing Pipeline Hook (`psGCodePostProcess`) that automatically patches sliced G-code using bed-safe coordinates. The PrusaLapse WebApp exposes plugin installation APIs and provides a 1-click installer and disable toggle in the Timelapse Setup panel.

**Tech Stack:** Python 3 (OrcaSlicer CPython plugin API, `pytest`), Next.js 16 (App Router), React 19, Node.js (`fs`, `path`).

**Spec:** [`docs/superpowers/specs/2026-11-04-orcaslicer-integration-design.md`](file:///C:/Users/cafub/Documents/Antigravity/dual-dalmatian/docs/superpowers/specs/2026-11-04-orcaslicer-integration-design.md)

## Global Constraints

- Pure Python plugin with zero compiled C-extension dependencies to ensure universal cross-platform compatibility.
- Safe bed boundary clamping: parking moves must never exceed `(bedMaxX - 10, bedMaxY - 10)` derived from G-code headers.
- Binary `.bgcode` guard: if a file has the binary `.bgcode` signature (`0x47 0x43 0x44 0x45`), bypass injection safely with a user notification.
- Non-blocking execution: slicing hook must gracefully exit if PrusaLapse server is offline without failing the slice.
- Respect active workspace rules: local git commits only; never run `git push` without explicit user permission.

## Review Focus

1. **Prusa MINI Bed Boundary Violation**: A print sliced with MINI bed (180x180 mm) must clamp park coordinates from the default 240x210 to (170, 170). Tested in Task 1.
2. **Binary `.bgcode` Container Pass-through**: Slicing with binary G-code enabled must leave file intact without corrupted text injection. Tested in Task 1.
3. **Relative Extrusion (`M83`) Preservation**: Injected G-code must enforce `M83` and restore pre-parking motion modes so layer retractions do not jam. Tested in Task 1.
4. **Offline PrusaLapse Server Handling**: Slicing while PrusaLapse is not running must return success without throwing unhandled exceptions. Tested in Task 2.
5. **Cross-Platform Plugin Path Resolution**: Detection and 1-click installation must resolve `%APPDATA%\OrcaSlicer\plugins` on Windows and `~/.config/OrcaSlicer/plugins` on Linux. Tested in Task 3.

import unittest
from prusalapse.injector import (
    is_binary_bgcode,
    parse_bed_boundaries,
    calculate_park_target,
    inject_timelapse_gcode,
)

class TestGCodeInjector(unittest.TestCase):
    def test_binary_bgcode_detection(self):
        self.assertTrue(is_binary_bgcode(b"GCDE\x01\x00\x00\x00binarypayload"))
        self.assertFalse(is_binary_bgcode(b"; generated by OrcaSlicer\nG28\n"))

    def test_bed_boundary_parsing(self):
        gcode = "; generated by OrcaSlicer\n; bed_shape = 0x0,250x0,250x210,0x210\nG28\n"
        max_x, max_y = parse_bed_boundaries(gcode)
        self.assertEqual(max_x, 250.0)
        self.assertEqual(max_y, 210.0)

    def test_bed_boundary_fallback(self):
        gcode = "; no bed header present\nG28\n"
        max_x, max_y = parse_bed_boundaries(gcode)
        self.assertEqual(max_x, 250.0)
        self.assertEqual(max_y, 210.0)

    def test_park_target_clamping_mk4(self):
        target_x, target_y = calculate_park_target(240.0, 210.0, 250.0, 210.0)
        self.assertEqual(target_x, 240.0)
        self.assertEqual(target_y, 200.0)

    def test_park_target_clamping_mini(self):
        target_x, target_y = calculate_park_target(240.0, 210.0, 180.0, 180.0)
        self.assertEqual(target_x, 170.0)
        self.assertEqual(target_y, 170.0)

    def test_layer_change_injection(self):
        gcode = (
            "; generated by OrcaSlicer\n"
            "; bed_shape = 0x0,250x0,250x210,0x210\n"
            "G1 Z0.2 F1000\n"
            ";AFTER_LAYER_CHANGE\n"
            ";[layer_z]\n"
            "G1 X50 Y50 E1.0\n"
            ";AFTER_LAYER_CHANGE\n"
            ";[layer_z]\n"
            "G1 X60 Y60 E2.0\n"
        )
        config = {
            "parkX": 240.0,
            "parkY": 210.0,
            "zHopHeight": 0.4,
            "settleTime": 300,
            "captureTime": 1200,
        }
        modified, count = inject_timelapse_gcode(gcode, config)
        self.assertEqual(count, 2)
        self.assertIn("M220 S99", modified)
        self.assertIn("G1 X240.0 Y200.0 F9000", modified)
        self.assertIn("M83 ; Strict relative extrusion", modified)
        self.assertIn("M220 S100", modified)
```

Implement pure-Python G-code injector module:
- `is_binary_bgcode(data: bytes) -> bool`: checks if first 4 bytes match `b"GCDE"`.
- `parse_bed_boundaries(gcode_text: str) -> tuple[float, float]`: parses regex `; bed_shape = ...` or `; printable_area = ...` extracting maximum coordinate pairs; defaults to `(250.0, 210.0)` if absent.

import unittest
import os
import json
import tempfile
from prusalapse.plugin import load_local_config, save_local_config, process_slicing_file

class TestPluginBridge(unittest.TestCase):
    def setUp(self):
        self.temp_dir = tempfile.TemporaryDirectory()
        self.config_path = os.path.join(self.temp_dir.name, "config.json")

    def tearDown(self):
        self.temp_dir.cleanup()

    def test_config_lifecycle(self):
        save_local_config({"host": "http://192.168.1.100:3000", "enabled": True}, self.config_path)
        loaded = load_local_config(self.config_path)
        self.assertEqual(loaded["host"], "http://192.168.1.100:3000")
        self.assertTrue(loaded["enabled"])

    def test_process_slicing_file_disabled(self):
        gcode_path = os.path.join(self.temp_dir.name, "test.gcode")
        with open(gcode_path, "w", encoding="utf-8") as f:
            f.write(";AFTER_LAYER_CHANGE\nG1 X10 Y10\n")
        
        # Disabled in local config
        save_local_config({"host": "http://127.0.0.1:3000", "enabled": False}, self.config_path)
        result = process_slicing_file(gcode_path, self.config_path)
        self.assertEqual(result["status"], "skipped_disabled")
        
        with open(gcode_path, "r", encoding="utf-8") as f:
            self.assertNotIn("M220 S99", f.read())
```
